# membercamp.com

Marketing site for MemberCamp (waitlist for now). Static HTML on GitHub Pages — public repo, free.

- The product app lives in the private `SourceQuarter/drupux` monorepo (`apps/membercamp`) and will run at `app.membercamp.com`.
- Custom domain in `CNAME`; DNS in AWS Route 53.
- Waitlist form: set `WAITLIST_URL` in `index.html` to the form link (Tally) before launch.
- Brand (logo, green) is a **placeholder** until MemberCamp's brand is decided.
